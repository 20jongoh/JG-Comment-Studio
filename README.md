# 맥락 스튜디오 (Context Studio)

**제이지그룹 AI PM 과제 — TRACK 2 / 로컬 마케팅 AI 에이전트 시연**

[2분 15초 시연 영상 보기](https://www.youtube.com/watch?v=L2jpt6J7oqM)

YouTube 영상 목록을 확인하고, 영상 설명·확보 가능한 자막에서 맥락 근거를 추출해 AI 댓글 초안을 준비하는 로컬 웹 대시보드입니다. 사용자가 댓글을 검토·승인하면 **본인이 등록한 테스트 영상에서만** 전용 Chrome을 열어 글자별 입력과 게시를 시연하고 결과를 검증합니다.

> **제출용 공개 소스 v0.1.4.** 최초 v0.1.0 소스에 v0.1.1~v0.1.4 패치를 반영해 정리했습니다. 개인 설정·브라우저 프로필·실행 기록은 포함하지 않았습니다. 실제 운영/대량 게시용 제품이 아니라 과제 시연용입니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| ① 영상 불러오기 | 지정 5개 YouTube 채널의 최신 영상 조회, 썸네일·제목·채널·날짜 표시, 본인 테스트 영상 연결 |
| ② 영상 선택 · 초안 | Gemini 또는 OpenAI로 분석, 자막 우선·제목/설명 대체, 인용 근거 표시, 40~120자 검증 |
| ③ 댓글 달기 | 사용자의 최종 승인, 전용 Chrome 프로필 `유튜브1`로 글자별 입력, 게시 상태 및 기록 확인 |

- 같은 영상 1회 게시 제한, 기본 일일 상한 10개(한국시간), SQLite 기록 저장
- 결과 미확인 시 재게시 잠금 유지, YouTube API 이중 조회를 통한 **기존 댓글 읽기 전용 재확인**
- API 없이 로컬 연습 화면 사용 가능. **가상 연습은 실제 YouTube 게시와 다르게 표시**
- 외부 5개 채널은 조회·AI 초안까지만, **실제 게시는 등록한 본인 테스트 영상만 허용**
- 실제 게시되는 테스트 댓글에 `[과제 시연]` 표시. 후기나 개인 경험을 꾸며내지 않도록 검토 단계 구성
- 추가 기능인 다중 프로필 자동 배정·급상승 영상 탐색은 미구현

## Windows 실행 방법

1. Python **3.11 이상** 및 Google Chrome을 설치합니다.
2. 이 저장소를 ZIP으로 받거나 Git으로 복제합니다.
3. 저장소 폴더에서 `install.bat`을 한 번 실행합니다. Python 가상환경 `.venv`가 만들어집니다.
4. `start.bat`을 실행하면 `http://127.0.0.1:8765`가 열립니다.
5. 먼저 **연습 데이터**의 영상 선택·로컬 입력 기능을 테스트하세요.
6. 실제 영상은 우측 상단 **연결 설정**에서 본인 YouTube Data API v3 키와 Gemini/OpenAI API 키를 입력한 뒤 사용합니다. AI 제공자에서 **사용 가능한 모델 ID**를 확인해 설정하세요.
7. 실제 게시 검증에는 본인 테스트 영상 URL, 영상 소유 채널 ID, 게시 계정 @핸들을 등록하고 대시보드에서 Chrome 전용 프로필을 열어 직접 로그인합니다.

**API 키와 로그인 정보는 소스코드나 `.env` 파일에 커밋하지 마세요.** 프로그램은 입력한 설정을 `runtime_data/settings.json`에 로컬 저장합니다. 이 디렉터리는 Git에서 제외합니다.

## 테스트

```bat
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
```

실제 YouTube 게시와 제삼자 서비스 호출은 현지 API 키/계정 및 YouTube UI 변화에 영향을 받습니다. 단위 검사는 실계정 게시가 아닌 모의 응답으로 실행됩니다.

## 보안 및 범위

- 프로그램의 HTTP 서버는 기본적으로 `127.0.0.1`에서만 실행합니다.
- 프로필 로그인 정보, API 키, SQLite 기록, 오류 캡처는 `runtime_data/`에 저장될 수 있습니다.
- 자막이나 영상 설명의 일부는 AI 제공자에게 전달될 수 있으니 개인 정보가 담긴 자료는 입력하지 마세요.
- 댓글 게시 전 사용자가 직접 내용을 승인해야 합니다.
- 자동 게시 확인과 API 사후 재확인은 구분하며, 확인 실패를 무조건 성공으로 기록하지 않습니다.
