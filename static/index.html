    Google Cloud에서 YouTube Data API v3를 사용 설정한 뒤 발급한 키입니다. 영상 정보 조회에 사용합니다.

    API 키는 이 컴퓨터의 설정 파일에 저장됩니다. 빈칸으로 저장하면 기존 키를 유지합니다. 공용 컴퓨터에서는 사용하지 마세요.
