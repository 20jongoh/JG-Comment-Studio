# 공개 전 보안 확인

이 저장소는 로컬 프로그램의 소스코드만 포함합니다. **실제 계정 데이터/키는 포함하지 않습니다.**

절대로 공개하면 안 되는 자료:
- `runtime_data/settings.json`, API 토큰·키, `.env`
- `runtime_data/profiles/` 아래 Chrome 프로필, 쿠키, 로그인 상태, 인증 정보
- `runtime_data/ledger.sqlite3`, 게시 기록 원본, 오류 캡처, 내부 테스트 자료
- `.venv` 패키지, 개인 영상·화면 녹화 원본

공개 전 `git status --short`와 `git ls-files`로 실제 올라갈 파일을 확인하세요. API 키를 실수로 공개했다면 파일 삭제만으로는 부족하며, 해당 키를 즉시 폐기·재발급하고 Git 기록에서도 제거해야 합니다.

처음 업로드 시에는 이 ZIP에 포함된 **공개용 파일만** GitHub에 올리고, 로컬에서 사용하던 프로그램 폴더를 드래그하지 마세요.
