## 실제 확인된 범위

YouTube 공식 API를 이용한 영상 조회, Gemini를 이용한 새 영상 초안 생성, 본인 테스트 영상에 대한 Chrome 입력·댓글 게시, 이후 YouTube API 사후 재확인을 확인했습니다.

**주의:** 본인 소유 영상과 단일 프로필에서 확인한 시연입니다. 외부 채널 대량 게시나 다중 계정 자동 운영을 시연하지 않았습니다. 제삼자에 대한 게시 허가를 의미하지 않습니다.
